# AdPulse-BI

Omnichannel Marketing Intelligence & AI-Powered Decision Support System

# Project Overview

AdPulse-BI is a marketing analytics project designed to evaluate digital advertising performance across multiple marketing channels. It aims to analyze campaign spending, revenue, conversions, and customer journeys to support data-driven marketing decisions.

# Project Objectives
The project focuses on measuring campaign effectiveness, comparing channel performance, analyzing customer behavior, and identifying opportunities to improve marketing ROI.

# Dataset
The project uses six related datasets: Channels, Campaigns, Ad_Groups, Daily_Performance, Conversions, and Touchpoints.
Tools & Technologies
Python (Pandas, NumPy, Matplotlib, Seaborn), SQL, Power BI, and Microsoft Excel.

# Project Workflow
The project follows three main stages: Python for data understanding, cleaning, and analysis; SQL for database management and analytical queries; and Power BI for interactive dashboards and business insights.

# Current Progress
Python data inspection, profiling, validation, and initial cleaning have been completed. Initial EDA visualizations have also been created to analyze channel spending, revenue, conversions, and monthly spending trends.

# Expected Deliverables
A cleaned and structured dataset, SQL database and analytical queries, interactive Power BI dashboards, and actionable marketing insights.

# Project Status
In Progress – Further analysis, KPI calculations, attribution analysis, SQL implementation, and Power BI development are planned.
